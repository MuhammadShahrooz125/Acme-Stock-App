## Acme Stock App

Acme Stock App is a Stock Management System developed using ASP.NET Core Web API following the N-Tier Architecture pattern. The application is designed to manage stock and product information through a structured, scalable, and maintainable architecture.

### Key Features
- N-Tier Architecture
- ASP.NET Core Web API
- Microsoft SQL Server Database
- Entity Framework Core (EF Core)
- Product CRUD Operations
- Authentication and Authorization
- SMTP Email Integration
- Google reCAPTCHA v3 Integration
- Unit Testing
- Integration Testing

### Technologies Used
C#, ASP.NET Core Web API, .NET 10, N-Tier Architecture, SQL Server, Entity Framework Core, SMTP, Google reCAPTCHA v3, xUnit
